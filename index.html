Textual Learning en desarrollo

C# · Unity · Editor Window · Visual Scripting

objetivo

Enseñar a programar a personas que se inician en la programación, mostrando en una ventana de Unity el código C# que se genera a partir de nodos de Unity Visual Scripting.

qué hace

  • Abre una ventana propia dentro de Unity, con su interfaz y su ruta de menú.
  • Lee el grafo de nodos que se arrastra a la ventana.
  • Reconoce los nodos del grafo mediante un mecanismo de detección automática; actualmente reconoce Start, Update, Debug.Log y sus valores.
  • Actualiza constantemente el código mostrado en la ventana.
  • Reconoce el orden de los nodos leyendo sus conexiones, para mostrar el código ordenado y limpio.
  • Muestra el código generado, con colores según cada tipo de palabra, dentro de un panel oscuro.

cómo se construyó

  • Creé el script VisualCodeWindow.cs para crear la ventana y su ruta de menú.
  • Implementé dentro de VisualCodeWindow.cs la lectura de los nodos y sus conexiones para mostrarlos en la ventana; pasé de hacerlo de forma manual a automatizar de a poco cada parte importante, hasta lograr una primera versión automatizada.
  • Implementé que el código mostrado se actualice constantemente cuando cambia el grafo.
  • Implementé colores distintivos para cada tipo de palabra, como en un editor de C#.

XR Remote Controller

C# · Unity · OpenXR

objetivo

Simulador de controladores XR para futuros proyectos

qué hace

  • Al poner la batería, los controles quedan disponibles.
  • La palanca (lever) enciende el panel de controles.
  • El joystick mueve la posición del avión.
  • Un dial controla su altura y otro su rotación.
  • La perilla (knob) aumenta o disminuye la velocidad.
  • Un texto sobre cada control muestra en tiempo real su estado: encendido, rotación, velocidad y altura.
  • Si se quita la batería con el panel funcionando, todo se apaga, aunque la palanca siga encendida.

cómo se construyó

  • Utilicé los recursos de XR Interaction Toolkit y XRI Examples como base para crear el simulador.
  • Programé un script para la batería: al ponerla, da energía a los controles y se activan; al sacarla, los controles se desactivan y el avión deja de funcionar.
  • Esta base me permite ahorrar tiempo al construir paneles de controles de maquinaria o de otro rubro con sistema de energía.

TOM: Tournament Management System en desarrollo

HTML · CSS · JavaScript · Visual Studio Code

objetivo

Gestionar torneos no oficiales de TCG con sistema de rondas suizas, inspirado en el TOM oficial de Pokémon.

qué hace

  • Define el nombre del torneo y el número de rondas a jugar.
  • Calcula el desempate automáticamente con OP% (Opponents' Win Percentage) y OPP% (Opponents' Opponents' Win Percentage).
  • Agrega y quita participantes; el rating es opcional y solo ordena el primer emparejamiento.
  • Genera cada ronda con emparejamientos de sistema suizo y registra el resultado con botones: victoria 3 puntos, empate 1 punto para cada uno y derrota 0.
  • Asigna un bye (victoria automática) cuando el número de jugadores es impar.
  • Muestra la clasificación ordenada por puntos, con el récord de victorias, derrotas y empates y los porcentajes de desempate.

cómo se construyó

  • Creé una navegación por pestañas (Configuración, Jugadores, Rondas y Clasificación), con un contador que muestra cuántos jugadores hay inscritos.
  • Guardé todo el estado del torneo en localStorage: jugadores, puntajes, byes, rondas, emparejamientos y resultados, para que no se pierda al recargar la página.
  • Programé el emparejamiento suizo: ordena a los jugadores por puntaje (y por rating en la primera ronda) y evita que se repitan rivales, salvo cuando ya no queda otra opción.
  • Implementé la asignación del bye al jugador con menor puntaje que aún no lo haya recibido, con puntuación al estilo Pokémon: 3 por victoria, 1 por empate y 0 por derrota.
  • Programé el desempate con OP% y OPP%: el porcentaje de victorias de los rivales y el de los rivales de los rivales, con un mínimo del 25% como en Pokémon.
  • Lo publiqué en GitHub Pages con licencia GPL 3.0, para usarlo desde el navegador sin descargar nada.
